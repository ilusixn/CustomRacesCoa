# The client exe is AFK64.exe (2026-11-13)

Our x64 client now builds as `AFK64.exe` instead of `CoA64.exe`. The reason is CoA Custom 2.0: it renamed the
package's client to `CoACustomRace.exe`, so a name of our own keeps the three apart at a glance — the package's exe,
the 1.9.x name and our build.

- `WoW/Source/CMakeLists.txt`: `WOW_OUTPUT_NAME` is `AFK64` (the 32-bit tool stays `Wow32`).
- `BuildCoA64.bat`: packages `bin\Win\AFK64.exe`, `AFK64.map` and `AFK64-<hash>.zip`.
- AFK Realm installs its build under this name (`CoaClientExe.Afk`) and starts it when present; the package's own exe
  stays as `.afk-backup`.
