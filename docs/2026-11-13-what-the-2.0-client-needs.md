# What the 2.0 client features need from ilusixn (2026-11-13)

CoA Custom 2.0's `CoACustomRace.exe` contains three things that are **not** in the pushed source (`races-port`
`6089eeaa`, tag `coa-custom-2.0`):

1. **A Vulkan render device** — `Engine/Source/Gx/CGxDeviceVulkan/CGxDeviceVulkan.cpp` is compiled into his exe
   (found by its `__FILE__` string) and is absent from the tree. With it came a new `GxApi_*` value (the tree knows
   only `D3d9`, `D3d9Ex`, `OpenGl`) and the `Vulkan\d3d9.dll` + `VulkanShaders` loading.
2. **Lumenveil, compiled in** — the whole renderer (fog, sun/moon shafts, lamp light, water, wet surfaces) with its
   cvars (`lumenveil`, `lumenveilDepthView`, `lumenveilLampTiles`, `lumenveilTime`), `Logs\Lumenveil.log`, the
   `lampdata.bin` / `liquiddata.bin` readers and the "Visual pack" choice (0 stock, 1 Lumenveil, 2 Azeroth
   Remastered). Upstream Lumenveil (`lumenveil/Lumenveil`) is 32-bit and hash-patches the 12340 client, so it cannot
   be dropped into the x64 client.
3. **The "Visual pack" selector** — `visuals` cvar plus its console command (`time: held at %02d:%02d on this
   screen` belongs to it).

Not needed: the dev menu (we have our own), Gilgoblin (data only, no client code in his exe) and the crash guard
(same markers as ours).

## What to ask for

A branch (or a zip) with the client tree that `CoACustomRace.exe` was built from, or at minimum:

- `Engine/Source/Gx/CGxDeviceVulkan/` (all files) and the `GxApi` enum / `CGxDevice::Create` additions it needs;
- every file that mentions `lumenveil` (his module, the shader loader and the `VulkanShaders` index/manifest reader);
- the `visuals` cvar registration and the `Vulkan\d3d9.dll` preload site;
- `Engine/Source/CMakeLists.txt` (or wherever the new sources are listed) and any `cmake/` files the shaders need.

## What we do with it

`voices-200` (2.0 base + all CoA64/Voices work) is the merge target. Order:

1. Fetch the branch, diff its `Engine/Source/Gx`, `CoA/Source/Runtime` and `CoA/Source/Modules` against
   `coa-custom-2.0`; anything that is already in `voices-200` (DXVK `Vulkan\` first, the AllRaces v12 tables,
   `EsteriaPackSkins`) is dropped from the diff.
2. Merge the remaining files; resolve against `CoA::Visuals::Start()` so `visuals 1` calls his Lumenveil entry instead
   of logging, and `visuals 2` keeps LuxVelum.
3. Build, test (`CoATests`), and compare the exe's strings/switches with `CoACustomRace.exe` the same way the v12
   tables were verified.
4. Ship `Vulkan\`, `VulkanShaders\`, `lampdata.bin`, `liquiddata.bin` with the client root (the 2.0 package already
   carries them).
