Jinyu / Ankoan playable race files for a WoW 3.3.5a (12340) client - from the SnowzoCraft server.

  Character\Jinyu\Male\   "Body 1" = river jinyu (JinyuMale.m2, skins, animations, textures)
  Character\Jinyu\Female\ "Body 2" = Ankoan (JinyuFemale.m2 ...)
  Interface\Custom_Glues\RACE_ICONS\RaceIcon_Jinyu_Male/Female.blp   create-screen icons

armour geosets), fins as a separate geoset.
