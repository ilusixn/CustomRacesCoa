# CoA Custom 1.9.5 (x64 client, test build)

Complete package: **this release alone is enough**. It is 1.9.2 plus the x64 client (`CoA64.exe`) with the Retail race adapter (Worgen and Dracthyr forms), a new world server, and all the Retail data those races need (no CDN download).

## New in 1.9.5
Slime Giant chest-only armor, Gnoll Scavenger (active) + Skinner, Kyrian/Venthyr hover fix, racial animations, saved form look at select. See PATCH-NOTES-1.9.5.txt.

## Download
- Download **every zip** on this page into one folder: Server + Client-1 to Client-9 (ten zips).
- Already on 1.9.2? Only Server + Client-6 to Client-9 are new.

Extract every zip into the same folder, run `CoA-Custom\Install-Custom.bat`, start the servers, then start the game with **CoA64.exe**.
Full steps: `INSTALL-GUIDE.txt`. Checksums: `SHA256SUMS.txt`. What changed and known issues: `PATCH-NOTES-1.9.5.txt`.
